AI security / Systems engineering

AgentShield

Make an agent’s access
visible before trusting it.

C11 · C++17 · Java 17 · Linux / WSL

Explore repository

AI agents can inherit credentials, privileges and access to local resources. AgentShield brings observed process exposure, policy decisions and audit evidence into a desktop console.

Engineering decision
A bounded C sensor gathers process facts; a C++ engine interprets risk and policy; Java consumes the process-boundary contract.
Security boundary
Observation and supervised execution have explicit limits. Missing visibility is uncertainty. This preview does not provide complete operating-system isolation.
Evidence to inspect
Threat model, policy documentation, audit design, synthetic Demo Lab and validation scope.

File & URL analysis

DataGuardian

Go · Next.js · PostgreSQL · Docker

File and URL inspection that presents structured findings and an explainable risk score.

Engineering focus & scope

A Go backend and Next.js interface inspect files and HTTP responses, persist findings and assign fixed scores by severity. Application-level SSRF controls restrict outbound URL inspection.

Boundary: inspection runs inside the Go application process. An application container is not a dedicated per-analysis sandbox. Findings do not guarantee safety or complete malware detection.

C · C++17 · Java · SHA-256

A privacy-focused duplicate-file auditor built across native processing and a desktop interface.

Engineering focus & scope

The project explores file comparison, hashing and integration between C, C++ and Java. Large-file behaviour, filesystem changes and memory use are important parts of reviewing a duplicate-file tool.

Boundary: duplicate findings depend on filesystem conditions and documented guarantees. No benchmark or throughput claim is made here.
